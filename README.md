# 🛒 ShopClone — Amazon-Style Shopping Website

A beginner-friendly Amazon-inspired e-commerce website built using **HTML**, **CSS**, and **JavaScript**. This project replicates core online shopping features such as product browsing, searching, cart management, and theme switching while focusing on responsive design and user experience.

---

## ✨ Features

* 🔝 Amazon-style sticky navigation bar
* 🔍 Real-time product search and filtering
* 🃏 Product cards with ratings and pricing
* 🛒 Add to cart functionality
* 🔢 Quantity tracking in cart
* ✕ Remove individual items from cart
* 🧹 Clear entire cart option
* 💰 Cart total price calculation
* 🌙 Dark / Light mode toggle
* 🔔 Toast notifications for user actions
* 📱 Fully responsive design (mobile and desktop)
* 💾 Local Storage support (cart and theme persist after page refresh)

---

## 🛠️ Technologies Used

| Technology        | Purpose                             |
| ----------------- | ----------------------------------- |
| HTML5             | Page structure and content          |
| CSS3              | Styling, layout, and dark mode      |
| JavaScript (ES6)  | Interactivity and application logic |
| Local Storage API | Persistent cart and theme data      |

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ShopClone.git
```

2. Navigate to the project folder:

```bash
cd ShopClone
```

3. Open `index.html` in your browser

**OR**

4. Run the project using **Live Server** in VS Code:

   * Right-click `index.html`
   * Select **Open with Live Server**
